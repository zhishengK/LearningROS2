## 🗺️ 学习路线

### 阶段 1：环境与基础

- [ ] 安装 Ubuntu + ROS2（如 Humble / Jazzy）
- [ ] 了解 ROS2 架构与 DDS
- [ ] 熟悉 `ros2` 命令行工具
- [ ] 跑通 turtlesim 示例

### 阶段 2：核心概念

- [ ] 工作空间与功能包（colcon）
- [ ] 节点 Node
- [ ] 话题 Topic（发布/订阅）
- [ ] 服务 Service
- [ ] 动作 Action
- [ ] 参数 Parameter
- [ ] 自定义消息与接口

### 阶段 3：进阶工具

- [ ] Launch 文件
- [ ] TF2 坐标变换
- [ ] URDF / Xacro 机器人建模
- [ ] RViz2 可视化
- [ ] Gazebo 仿真
- [ ] rosbag2 数据录制与回放

### 阶段 4：综合应用

- [ ] Navigation2 导航
- [ ] SLAM 建图
- [ ] MoveIt2 机械臂（可选）
- [ ] 完成一个完整的实战项目
